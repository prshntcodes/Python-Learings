
# Student Management System

A simple command-line Student Management System built with Python using Object-Oriented Programming (OOP) principles.

## Features

* Add new student details
* View all student records
* Update student details
* Delete student records
* Search for a student by Roll Number
* Store and manage marks for Physics, Chemistry, and Mathematics

## Subjects

The system currently manages marks for:

* Physics
* Chemistry
* Mathematics
